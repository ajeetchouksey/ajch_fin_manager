# Older documents

These describe earlier versions of the project and are kept for reference only. They do not describe the current system; for that, see the [root README](../../README.md) and the [ADRs](../adr/README.md).

- **Local Python app era:** the original laptop app (`server.py`, `fincore/`, `static/`) with SQLite. The code was retired in October 2026 and is kept on the `archive/python-app` branch, including the German and Indian tax calculations (`fincore/tax_de.py`, `fincore/tax_in.py`).
- **Worker and AI onboarding era:** `PHASE_1.md`, `PHASE_2_1_QUICK_START.md`, `PHASE_2_5c_FINAL_VERIFICATION.md`, `IMPLEMENTATION_SUMMARY.md`, `PROGRESS_UPDATE.md`, `CI_CD_SETUP.md`, `DEPLOYMENT_CHECKLIST.md`, `TESTING_GUIDE.md`, `TESTING_SUITE.md`, and the reports in `claude/`. They describe the root Worker with Gemini-based onboarding and a profile stored in D1. The profile has since moved into each user's Ledger, and the onboarding routes are being retired.
